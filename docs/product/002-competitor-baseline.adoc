= Pricing Competitor Baseline
:revdate: 2026-09-20

This benchmark records only capabilities supported by local evidence or current official competitor documentation. Unsupported competitor conclusions remain NOT_VERIFIED.

== Comparison set

* Medusa v2
* Vendure
* Sylius

== Current evidence

[cols="3,3,3,3",options="header"]
|===
|Capability |Pricing |Medusa v2 |Vendure / Sylius
|Price-set identity and multi-currency definitions |IMPLEMENTED: PriceSetDTO and PriceDefinitionDTO |VERIFIED: PriceSet groups resource prices and supports multiple currency-coded prices |Vendure: NOT_VERIFIED for equivalent PriceSet identity. Sylius: NOT_VERIFIED in this pass.
|Contextual price lists/rules |IMPLEMENTED: list- and price-level exact-match context |VERIFIED: PriceList and price rules constrain prices by context such as region/customer group |Vendure: VERIFIED in Platform Price Rules through price lists with customer-group/customer-specific rule patterns. Sylius: NOT_VERIFIED.
|Quantity tiers |IMPLEMENTED: inclusive minimum/maximum quantity bounds |VERIFIED: min_quantity/max_quantity tier prices participate in calculation |Vendure: VERIFIED in Platform Price Rules as quantity breaks. Sylius: NOT_VERIFIED.
|Deterministic best-price selection |IMPLEMENTED: explicit priority, specificity, tier, amount, revision, and stable id ranking |VERIFIED: calculatePrices returns a best-matching price and documents context/rule matching; exact tie-break parity is NOT_VERIFIED |Vendure/Sylius: exact deterministic tie-break parity NOT_VERIFIED.
|Reference/original versus effective price |IMPLEMENTED as referenceAmountMinor metadata distinct from selected amount |VERIFIED: calculated price and original price are distinct in calculation output |Vendure/Sylius: NOT_VERIFIED in this pass.
|Tax-inclusive metadata boundary |IMPLEMENTED as passive taxIncluded metadata; Taxating owns calculation |VERIFIED: Pricing Module advertises tax-inclusive pricing behavior |Vendure core exposes priceIncludesTax in price-calculation contracts. Sylius: NOT_VERIFIED.
|Selection provenance and historical replay |IMPLEMENTED snapshot/replay contract; durable storage remains open |No equivalent replay/provenance contract verified from reviewed pricing documentation |No equivalent replay/provenance contract verified from reviewed documentation.
|===

== Boundary decision

Pricing should continue closing auditability, durable history, and typed neighbor-consumption contracts rather than absorbing promotions, tax calculation, FX, or order-total logic. Competitor capability alone is not a reason to duplicate another SmartResponsor component's ownership.
